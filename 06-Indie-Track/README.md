## 1. Sự thật về làm game Indie

> 💡 **Indie không phải "lập trình viên làm game một mình". Indie là "làm chủ một sản phẩm trọn vẹn".** Code chỉ là 1 trong 5-6 mảng bạn phải lo.

```
        MỘT GAME INDIE THÀNH CÔNG CẦN:
   ┌──────────┬──────────┬──────────┬──────────┬──────────┐
   │  Code    │  Design  │ Art/Audio│Production│ Marketing│
   │ (bạn đã  │ (trái    │ (đủ dùng │ (ship    │ (sống    │
   │  học)    │  tim)    │ /thuê)   │  được)   │  còn)    │
   └──────────┴──────────┴──────────┴──────────┴──────────┘
```

**Sự thật phũ phàng:**
- Đa số game indie **thất bại về thương mại** — không phải vì code tệ, mà vì **không ai biết tới** hoặc **không vui**.
- **Marketing & game feel** quan trọng hơn kiến trúc code hoàn hảo.
- **Scope (phạm vi) là kẻ giết người số 1** — game quá tham vọng = không bao giờ xong.

## 3. Lộ trình Indie theo giai đoạn kỹ thuật

| Bạn đang ở | Làm Indie thế nào |
|-----------|--------------------|
| **Intern** | Tập trung học code. Chỉ cần làm game jam để nếm "làm game trọn vẹn". |
| **Junior** | Bắt đầu học [game design](./game-design.md). Làm 2-3 prototype "vui". Tham gia game jam đều. |
| **Mid** | Ship một game nhỏ thật (itch.io/mobile). Học [scope](./production-and-scope.md) + [marketing cơ bản](./marketing-and-release.md). |
| **Senior** | Có thể tự làm & ship game thương mại (Steam). Hiểu cả [business](./business-and-funding.md). |

## 4. Nguyên tắc vàng cho Indie

1. **🎯 Finish games.** Ship một game nhỏ tệ > không ship game hay tưởng tượng. Kỹ năng "hoàn thành" quý nhất.
2. **✂️ Cut scope brutally.** Game của bạn nên nhỏ hơn 3 lần so với bạn nghĩ.
3. **🎮 Fun first.** Prototype gameplay cốt lõi trước. Nếu prototype không vui, đồ họa đẹp cũng vô ích.
4. **📣 Market early.** Bắt đầu marketing từ khi mới làm, không phải lúc ship.
5. **💰 Don't quit your job (yet).** Làm indie bán thời gian/buổi tối trước khi all-in. Có thu nhập từ job công ty trong khi xây.
6. **🤝 You can't do everything alone.** Biết khi nào thuê/hợp tác (artist, sound, marketing).

---

## 5. Tại sao đi làm công ty TRƯỚC khi all-in Indie?

> Bạn chọn cả "đi làm công ty" và "Indie" — đây là kết hợp khôn ngoan nhất:

- Công ty dạy bạn **kỷ luật kỹ thuật, quy trình, làm việc nhóm, ship sản phẩm thật** — khó tự học.
- Bạn có **thu nhập ổn định** để giảm áp lực khi làm indie.
- Bạn **xây kỹ năng + vốn + network** trước khi nhảy.
- Làm indie nhỏ buổi tối để **giữ lửa & học phần ngoài-code** (design, marketing).

Khi indie của bạn đủ tiềm năng (hoặc đủ tiết kiệm), mới cân nhắc all-in.
