# ✅ Intern — Checklist Tự Đánh Giá

[⬅️ Resources](./resources.md) | [Lên Junior ➡️](../02-Junior/README.md)

> Tick khi bạn **thực sự làm được**, không phải "đã xem qua". Cần tick ~90% để tự tin lên Junior.

---

## C# Nền tảng
- [ ] Viết được class với field, property, method.
- [ ] Hiểu và dùng được kế thừa (`: MonoBehaviour`, base class).
- [ ] Dùng thành thạo `List<T>`, mảng, `foreach`, `for`.
- [ ] Dùng `enum` để quản lý trạng thái.
- [ ] Hiểu `public`/`private` và khi nào dùng cái nào.
- [ ] Tự viết được logic phức tạp vừa (vd: tính điểm combo, spawn theo pattern).

## Unity Editor
- [ ] Tạo/sắp xếp GameObject, gắn Component thành thạo.
- [ ] Tạo và dùng Prefab, hiểu prefab override.
- [ ] Dùng Inspector để chỉnh giá trị, hiểu `[SerializeField]`.
- [ ] Quản lý Scene, chuyển scene bằng code.
- [ ] Tổ chức Project (thư mục Scripts, Prefabs, Art...).

## MonoBehaviour & Logic
- [ ] Giải thích được vòng đời (`Awake`/`Start`/`Update`/`FixedUpdate`).
- [ ] Dùng đúng `Update` cho logic, `FixedUpdate` cho vật lý.
- [ ] Dùng `Instantiate` và `Destroy` đúng cách.
- [ ] Dùng Coroutine cơ bản (`IEnumerator`, `yield return`).
- [ ] Dùng `[SerializeField]` thay vì `public` để lộ biến ra Inspector.

## Vật lý & Input
- [ ] Cho object di chuyển bằng Rigidbody đúng cách.
- [ ] Phân biệt Collision vs Trigger, dùng đúng.
- [ ] Xử lý input bàn phím/chuột/touch.
- [ ] Làm ground check cho nhân vật nhảy.

## UI & Audio
- [ ] Tạo UI: điểm số, mạng, menu, game over (dùng TextMeshPro).
- [ ] Gắn sự kiện cho Button.
- [ ] Phát nhạc nền và SFX.

## Công cụ & Thói quen
- [ ] Dùng Git: commit, push, pull, branch cho dự án.
- [ ] Đọc Console, hiểu stack trace, tự sửa lỗi cơ bản (NullReference...).
- [ ] Dùng `Debug.Log` để debug có chiến lược.
- [ ] Đặt tên biến/hàm rõ ràng, code đọc được.
- [ ] Build game ra file chạy được (PC hoặc WebGL).

## Dự án (BẰNG CHỨNG QUAN TRỌNG NHẤT)
- [ ] Hoàn thành Project 1 (Pong/Flappy).
- [ ] Hoàn thành Project 2 (Runner/Breaker).
- [ ] Hoàn thành Project 3 (2D Platformer).
- [ ] Ít nhất 1 game đã build + push GitHub + có README.
- [ ] (Bonus) Tham gia ít nhất 1 game jam.

## 🧪 Bài test tốt nghiệp Intern

> Tự cho mình một đề bài mới (không xem tutorial), ví dụ:
>
> **"Làm game top-down: nhân vật di chuyển 4 hướng, né kẻ địch sinh ngẫu nhiên, ăn điểm, 3 mạng, có màn hình game over và high score."**
>
> Bạn tự làm xong trong **2-3 ngày** không cần tutorial từng bước?
> - ✅ **CÓ** → Bạn đã sẵn sàng lên [Junior](../02-Junior/README.md)!
> - ❌ **CHƯA** → Quay lại làm thêm dự án, vá lỗ hổng. Đừng vội.
