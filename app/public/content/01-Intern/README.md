# 🌱 Level 1: INTERN (Người Mới Bắt Đầu)

[⬅️ Về trang chủ](../README.md) | [Skills](./skills.md) · [Projects](./projects.md) · [Resources](./resources.md) · [Checklist](./checklist.md)

> ⏱️ **Thời gian:** 3-6 tháng (toàn thời gian)
> 🎯 **Mục tiêu cuối level:** Tự làm xong 2-3 game nhỏ hoàn chỉnh mà không cần tutorial cầm tay từng bước.

---

## 1. Bạn là ai ở level này?

Bạn là người **mới hoàn toàn hoặc gần như mới**. Mục tiêu không phải làm game hay, mà là:
- Làm quen với **tư duy lập trình** và **ngôn ngữ C#**.
- Hiểu **Unity Editor** hoạt động thế nào.
- Tự dựng được những game **đơn giản nhưng hoàn chỉnh**.
- Xây dựng **thói quen** tốt (Git, ghi chú, debug).

> ⚠️ Đừng cố làm game lớn ở đây. "Hoàn thành một game nhỏ" giá trị gấp 10 lần "làm dở một game lớn".

---

## 2. Tư duy quan trọng nhất ở Intern

> **"Hoàn thành" quan trọng hơn "hoàn hảo".**

Người mới hay sa vào: thêm tính năng mãi, sửa đồ họa mãi, không bao giờ xong. Hãy tập **đóng gói một game nhỏ từ đầu đến cuối** — có màn hình bắt đầu, có gameplay, có thắng/thua, có restart. Đó là kỹ năng quý nhất.

---

## 3. Lộ trình học trong level (thứ tự gợi ý)

```
Tuần 1-3:   C# căn bản (biến, hàm, vòng lặp, class, OOP cơ bản)
Tuần 4-5:   Làm quen Unity Editor + MonoBehaviour lifecycle
Tuần 6-8:   Game 1 — Pong / Flappy Bird (input, vật lý 2D, va chạm)
Tuần 9-12:  Game 2 — Endless Runner / Brick Breaker (spawn, score, UI)
Tuần 13-16: Game 3 — 2D Platformer nhỏ (state, animation, level)
Tuần 17-20: Polish, học Git cho dự án, làm lại 1 game cho "đẹp"
Tuần 21-24: Ôn tập, vá lỗ hổng kiến thức, chuẩn bị lên Junior
```

Chi tiết kỹ năng: [skills.md](./skills.md). Chi tiết dự án: [projects.md](./projects.md).

---

## 4. Phạm vi kiến thức (tóm tắt)

| Mảng | Cần đạt được |
|------|--------------|
| **C#** | Biến, kiểu dữ liệu, if/else, vòng lặp, hàm, class, OOP cơ bản (kế thừa, đóng gói), List, enum |
| **Unity Editor** | GameObject, Component, Prefab, Scene, Inspector, Hierarchy, Project window |
| **MonoBehaviour** | `Awake`, `Start`, `Update`, `FixedUpdate`, `OnCollision`, `OnTrigger` |
| **Vật lý** | Rigidbody, Collider, va chạm, trigger (2D trước, 3D sau) |
| **Input** | Đọc bàn phím/chuột/touch cơ bản |
| **UI** | Canvas, Button, Text, Image, hiển thị điểm số |
| **Âm thanh** | AudioSource, AudioClip phát nhạc/SFX |
| **Công cụ** | Git cơ bản, đọc Console, dùng Debug.Log |

## 5. ✅ Cách đánh giá ĐÚNG bạn đã qua Intern

Bạn KHÔNG qua Intern chỉ vì "học được X tháng". Bạn qua khi:

- ✅ Tự làm được **2-3 game nhỏ hoàn chỉnh** (có start, play, win/lose, restart) **không cần tutorial từng bước**.
- ✅ Khi gặp lỗi đỏ trong Console, bạn **đọc hiểu và tự sửa** được lỗi cơ bản.
- ✅ Hiểu và giải thích được vòng đời MonoBehaviour.
- ✅ Dùng được Git (commit, push, branch) cho dự án của mình.
- ✅ Tự nghĩ ra một tính năng nhỏ và **tự code được** mà không cần ai chỉ.

👉 Dùng [checklist.md](./checklist.md) để chấm chi tiết.

> 🧪 **Bài test tự kiểm tra:** Cho bạn yêu cầu "làm game tránh chướng ngại vật, ăn điểm, 3 mạng, có màn hình game over". Bạn có thể tự làm xong trong 2-3 ngày không cần tutorial không? Nếu CÓ → bạn đã sẵn sàng lên Junior.

## 6. Lỗi thường gặp ở Intern (tránh ngay)

| Lỗi | Hậu quả | Cách tránh |
|-----|---------|-----------|
| Tutorial hell (xem mãi không làm) | Không bao giờ tự code được | Xem xong phải tự làm lại không nhìn |
| Làm game quá lớn | Bỏ dở, nản | Làm game nhỏ, hoàn thành 100% |
| Không dùng Git | Mất code, không có lịch sử | Học Git ngay từ game đầu |
| Copy code không hiểu | Không lên trình | Đọc hiểu từng dòng trước khi dùng |
| Bỏ qua C# nền tảng | Lúc nào cũng bí logic | Học chắc C# trước khi vọc Unity sâu |
