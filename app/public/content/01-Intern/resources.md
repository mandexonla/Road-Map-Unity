## 📖 Tài liệu tham chiếu (đọc dần, không cần thuộc)

- **Unity Manual** (docs.unity3d.com/Manual) — sách hướng dẫn chính thức.
- **Unity Scripting API** — tra cứu hàm/class. Bạn sẽ dùng cả đời.
- **Unity Microgame templates** — template có sẵn để mod, học nhanh.

## 🛠️ Công cụ cần cài

| Công cụ | Mục đích |
|---------|----------|
| **Unity Hub** | Quản lý version Unity |
| **Unity Editor LTS** | Dùng bản LTS (Long Term Support) cho ổn định |
| **Visual Studio Community** hoặc **Rider** | Viết code (Rider tốt hơn nhưng có phí; sinh viên free) |
| **Git** + **GitHub Desktop** (hoặc dòng lệnh) | Version control |
| **GitHub / GitLab account** | Lưu code online |

> 📌 **Chọn phiên bản Unity:** Luôn dùng bản **LTS** mới nhất cho người mới. Đừng dùng bản beta/alpha.

## ⏰ Lịch học mẫu (toàn thời gian, 1 ngày)

```
Sáng (3-4h):  Học kiến thức mới (C#/Unity) + làm bài tập nhỏ
Chiều (3-4h): Làm dự án (áp dụng cái vừa học)
Tối (1-2h):   Đọc/xem nội dung mở rộng, ghi chú, tham gia cộng đồng
```

> Quan trọng: **Buổi chiều làm dự án là phần học sâu nhất.** Đừng để cả ngày chỉ xem video.

## ⚠️ Cảnh báo về tài nguyên

- **Đừng mua 10 khóa học Udemy rồi không học cái nào.** Một khóa làm hết > mười khóa bỏ dở.
- **Đừng xem tutorial mà không gõ lại code.** Xem thụ động = quên 90%.
- **Tránh nội dung quá cũ** (Unity 5, 2017...) cho phần Editor/UI vì giao diện đã đổi nhiều. Logic C# thì vẫn ổn.
