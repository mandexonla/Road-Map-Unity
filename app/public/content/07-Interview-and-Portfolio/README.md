## Nguyên tắc cốt lõi

1. **Portfolio > bằng cấp.** Trong game dev, **sản phẩm bạn làm** nói to hơn mọi thứ khác.
2. **Show, don't tell.** "Tôi biết tối ưu" < "Tôi giảm 40% frame time, đây là Profiler".
3. **Chất > lượng.** 2 dự án xuất sắc > 10 dự án nửa vời.
4. **Kể câu chuyện kỹ thuật.** Nhà tuyển dụng muốn thấy bạn **tư duy** thế nào, không chỉ kết quả.

## Lộ trình chuẩn bị theo level

| Level | Trọng tâm |
|-------|-----------|
| **Intern → Junior** | Build 2-3 dự án hoàn chỉnh, có GitHub + video. Học C# coding test cơ bản. |
| **Junior → Mid** | 1 dự án thể hiện kiến trúc + đóng góp codebase. Luyện coding test + Unity-specific. |
| **Mid → Senior** | Dự án thể hiện chuyên môn sâu + leadership. Luyện system design. |
