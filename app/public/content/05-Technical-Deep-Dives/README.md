## 💡 Cách dùng phần này

1. Khi một file level (vd `02-Junior/skills.md`) link tới đây → đọc phần tương ứng.
2. Mỗi file có đánh dấu độ sâu: 🟢 Cơ bản (Junior) · 🟡 Trung cấp (Mid) · 🔴 Nâng cao (Senior).
3. Đừng cố đọc hết một lúc. Đọc đúng cái bạn đang cần cho dự án hiện tại.
